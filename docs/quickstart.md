# 快速接入 MYLEVIS HUB

完整、现行的操作步骤以[官网接入文档](https://mylevis.com/docs/mcp-hub/)为准。本页帮助你理解连接前要准备什么，以及连接后如何验证。

## 前置条件

- MyLevis 账号，以及从[账号中心](https://mylevis.com/account/?tab=mcp)取得的 MYLEVIS HUB 远程 MCP 地址和个人密钥。
- 支持远程 MCP（Streamable HTTP）和自定义认证头的 AI 客户端。官网列有 Claude、Cursor、ChatGPT、WorkBuddy、千问办公等应用的接入要点；不同版本的菜单和能力可能不同。
- 使用某个第三方服务前，确认该服务当前可用，并满足对应授权与参数要求。

## 第一步：取得地址和密钥

登录官网，在账号中心的 MYLEVIS HUB 接入页创建密钥。官网提供“搜索工具”和“指定 MCP 服务”两种范围。密钥完整内容只在创建时展示一次，请保存到安全位置；遗失或疑似泄露时撤销旧密钥并重建。

**不要把 `https://mylevis.com/mcp/` 当成 MCP 服务地址。** 连接用的地址必须从账号中心复制。

## 第二步：配置客户端

根据客户端设置页或配置文件格式，填写远程 MCP 地址，并设置认证头：

```text
Authorization: Bearer <你的个人密钥>
```

[JSON 模板](../config/mylevis-hub.example.json)展示了官网文档中的通用 `mcpServers` 结构。它只是占位符示例；不要直接提交填有真实密钥的副本。某些客户端的配置格式或菜单不同，应按该客户端的当前说明映射相同字段。如果入口不支持自定义认证头，需要换用支持该能力的入口或版本。

## 第三步：连接并验证

保存后测试连接或检查服务状态，再查看客户端列出的工具：

- **搜索工具密钥**：通常先用 `search_tools` 找候选，再按实际返回的 `tool_id` 和参数格式调用 `execute_tool`。
- **指定服务密钥**：客户端直接列出所选服务当前开放的业务工具，按显示的参数格式调用。

若工具列表为空，先确认密钥范围、服务授权、客户端是否传入认证头，并尝试刷新工具列表。不要把密钥粘贴到公开 Issue 或不受信任的对话中。

## 费用与结果核对

按实际业务工具调用和官网现行单价扣除积分；一次对话可能调用多个工具。外部 AI 应用自身的会员、模型和其他费用另计。连接、刷新工具列表和搜索候选的计费规则见[官网文档](https://mylevis.com/docs/mcp-hub/)；套餐与试用条件见[价格页](https://mylevis.com/pricing/)。
